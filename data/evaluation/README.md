# RAG评测集

66条人工规则式编写并经程序检查证据编号的项目内部评测题，54条有答案，12条无具体答案。由本次开发创建，尚未经独立业务专家盲审，不是公开基准。
按文档主题分组：开发集22条，测试集44条；两组的有答案主文档不交叉。知识库对两组均完整可见，测试题不用于阈值选择。之前已见的16条冒烟题不是独立测试；本测试集存在相近题型，属于内部留出评测，不应当作外部泛化证明。
每条包含参考答案和 evidence_groups：组间为需要共同覆盖的证据，组内为可互相替代的片段。编号和文本摘要验证用于防止语料更新后沿用失效标注。
无答案题可能检索到相关但没有所问事实的片段；检索返回空的比例不是模型拒答正确率，最终拒答需要独立检查生成结果。

## 查询改写端到端诊断

`query_rewrite_cases.jsonl` 为另建的30条内部诊断对话：口语、关键条件、多轮补充、条件变更、无答案各6条；24条有答案、6条无答案。包含已讨论失败场景，不是新的盲测集，不用于调参。

运行 `python scripts/evaluate_query_rewrite.py`（先设置 `PYTHONPATH=src`），中断可用 `--resume`。会调用配置的外部模型，产生接口费用；运行前应确认数据允许发送。

流程：实际聊天图 → 记录模型工具查询及证据 → 用户原话保留历史后检索 → 同提示生成对照回答 → 模型裁判审计。原话与首次模型查询各Top3，实际Agent多查询证据另记。写工具被评测器阻止，独立内存会话不写生产检查点。

完整记录默认保存在忽略上传的 `work/query-rewrite-evaluation.json`，报告见 `docs/query-rewrite-evaluation.md`。模型裁判判断需人工复核，不能等同于真实业务准确率。
