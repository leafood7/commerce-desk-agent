# 政策证据检查

```text
用户消息 → check_policy_evidence → validate_decision
→ 证据不足：生成知识库工具调用 → tools
→ 证据足够：复用指定片段
→ call_model → 回答／继续调用工具
```

`policy_check`记录本轮问题、模式、片段ID与理由，随会话检查点保存。证据仅来自与真实调用ID配对的工具结果；虚构ID不能授权复用。检查失败时记录错误并回退原工具流程。

例如用户从“不喜欢耳机”更正为“收到就坏了，签收20天”，重新检索质量问题规则，先说明常规窗口不等于质量责任截止期，再查询具体订单。

原30题模型裁判27→28条正确，新20题16→19条；有一条旧题退化，仍存在条款漏检。完整结果、费用开销与复现见 [评测说明](evaluation.md)。
