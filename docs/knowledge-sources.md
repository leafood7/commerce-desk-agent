# 知识库来源与适用范围

知识库包含18份电商客服演示政策、76个片段，保存在 `data/knowledge/`。逐文件来源、适配说明、版本与校验摘要见[来源清单](../data/knowledge_sources.json)，该清单记录的检查日期为2026-10-21。

## 规则如何形成

公开参考包括市场监管总局、国家税务总局和京东消费者帮助中心。项目提取与退换货、优惠券、物流、会员及发票相关的原则，再统一成 CommerceDesk 演示规则。每份来源的适用范围单独记录，来源元数据放在政策目录之外，避免检查说明和 URL 被当成回答正文检索。

项目服务目标与外部参考分开标注。例如48／72小时、部分会员商品15天、30天自助开票等内容属于项目约定，不代表统一行业承诺；项目黑金会员也不等同京东 PLUS。

## 工具与知识的边界

| 内容 | 当前能力 |
| --- | --- |
| 政策 | 解释条款、核对条件、引用来源 |
| 订单 | 查询演示订单的实际字段 |
| 催单 | 本地申请、审批与工单登记 |
| 退款、退券、开票 | 仅解释规则，没有实际执行接口 |
| 激活、实物完好、实际签收时刻 | 订单工具不提供，需补充信息或人工核实 |

使用真实业务资料前，应按实际商城规则重新整理、核验并维护版本。原扩充阶段的冲突处理与失败记录见[历史报告](history/2026-10-21-policy-expansion.md)。
