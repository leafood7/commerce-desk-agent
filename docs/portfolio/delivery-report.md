## 用到的技术与实际困难

使用Python编排现有Docker种子与Node/Playwright浏览器场景，读取服务端模式先确认无模型调用条件；使用环境开关仅为演示保留结束截图，普通测试仍保持失败截图。交付核对使用SHA256、只读容器检查及本地Markdown链接解析，不导出账号、SQL、会话认证或私有图检查点。

实际困难首先是文档漂移：旧启动页与历史“未完成”文字可能误导新评审。保留历史原文并加范围提示，当前入口单独统一，避免抹掉实验历史。

复演首个启动脚本使用了当前Playwright CLI不支持的视频/截图参数，浏览器用例尚未执行；改为配置环境开关。一次补拍又因从frontend目录读取容器凭据时用了错误相对路径，在场景前失败；修正路径和失败即停后通过。相关失败保留在私有日志，没有放宽业务断言。截图检查还确认列表可能保留旧加载状态，材料明确以当前流程详情为准，没有借收口扩展UI重构。
