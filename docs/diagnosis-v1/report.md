## 后续路线与具体措施

### 优先级一：多意图取证与证据适用范围

1. 对018这类问题，区分“退货资格”和“加急发货”两个子问题，给每个子问题记录已覆盖／缺失的政策依据。
2. 优先验证在现有前置步骤输出子问题及必要证据需求，再进行有上限的补检索；不先增加全局后审调用。
3. 对商品券／运费券等容易串用的政策，选择小范围做有来源的适用对象标注，比较“不过滤／按适用范围过滤”；保留通用规则及例外，不仅按关键词删文件。
4. 验收同时检查覆盖、范围混用、遗漏和正常问题完成度。人工补证有效不等于自动补证已有效，需要新的机制对照。

### 优先级二：条件关系与措辞保真

1. 把015作为公开回归，区分“满足A后适用B”和“只有A才能B”；对“不承诺”“不当然”等程度词单独列出判分点。
2. 下一阶段先比较保留原条件连接词的短引／受约束表达，与当前自由改写的差异；不依靠继续增加一般性提示就宣称解决。
3. 若证据齐全、适用范围正确后仍反复强化条件，再把单次语义后审作为对照臂，测漏判、误拒答、费用和等待时间。当前没有执行该候选，也没有后审收益结论。

### 配套：来源与工具边界

保留候选中的本轮证据白名单和真实工具字段渲染作为可复用工程措施，但其机械保证与语义质量分开验收。当前两项能力场景未复现旧错误，不把工具能力问题预设为下一阶段最主要投入。
