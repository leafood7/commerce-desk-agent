# 查询改写端到端评测

## 这次评什么

固定现有混合检索加重排策略，不修改生产提示词、不调阈值。检验模型在实际对话中是否正确调用知识库、保留用户条件，以及返回证据能否支持最终回答。

30条自建对话分为口语、关键条件、多轮补充、条件变更、无答案五类，每类6条。其中24条有答案，6条所问事实不在知识库中。这是包含已知问题的内部诊断集，不是独立公开基准。

## 调用链

用户消息
→ `call_model()`：在真实提示词和工具定义下，让模型选择工具与参数
→ `ToolNode`：运行知识库工具；评测替身阻止业务写工具
→ `search_policies()`：混合检索、RRF融合、重排、过滤，返回Top3
→ 再次 `call_model()`：利用工具结果回答；多轮案例继续相同独立会话
→ `extract_turn()`：按工具调用ID记录查询及对应证据
→ `raw_query()`：保留所有历史用户消息及最新更正，构造原话对照
→ 两路相同提示词生成：分别使用原话证据和末轮首次模型查询证据
→ `evidence_metrics()`：按标注检查必要证据覆盖
→ 模型裁判：检查条件保留、回答正确性、依据和无答案拒答
→ `summary()`：汇总改写收益、损失及故障线索。

最终Agent回答可以利用前轮真实工具证据，因此同时记录整段对话证据并集。首次查询对比只给末轮一次Top3预算。原话多轮对照是拼接用户历史，而不是增加一个独立改写模型。前轮助手回答可帮助理解对话，但不能替代工具证据。

## 运行与复现

```powershell
$env:PYTHONPATH='src'
$env:HF_HUB_OFFLINE='1'
.venv/Scripts/python.exe scripts/evaluate_query_rewrite.py
# 中断后继续
.venv/Scripts/python.exe scripts/evaluate_query_rewrite.py --resume
```

需要现有模型接口、嵌入与重排模型缓存、知识库索引。会向配置的外部接口发送测试对话、检索片段及答案，并产生费用。本次已获用户明确授权使用DeepSeek接口。没有使用真实客户资料，不执行业务写入。

完整逐案记录在 `work/query-rewrite-evaluation.json`（不上传Git）：含原话、模型查询、前后轮工具证据、回答、裁判理由、数据与语料指纹。裁判如仅缺少末尾一个根对象闭括号，补齐并记录原文及修复标记；其他格式错误最多重试三次并保留响应；不会因分数低而重试挑选答案。当前脚本不是网页HTTP或重启恢复测试。

## 解释结果的边界

证据标注按片段ID检查，未标注的等价政策可能造成严格命中统计偏低；需要逐案核实。模型裁判与被评Agent使用同一模型家族，有偏差且单次结果有随机性，不能把模型判断直接当成人工金标准。条件保留与检索失败同时发生也不等于证明前者导致后者。本次只诊断，不利用这些题调生产参数，也不能承诺真实业务达到相同效果。

## 已确认的失败示例

“手机就拆开瞅了一眼，也不能退了？”被模型查询为“手机拆封后能否退货 七天无理由退货”。返回了数字内容、一般例外和卫生用品条款，未返回实物手机合理查验条款。Agent因此保守拒答。该案例同时提示查询具体条件表达和检索排序问题，仅凭一次结果不能认定唯一原因。

“买衣服就上身比划了一下，吊牌还在，没弄脏，能退不？”的改写保留了吊牌、试穿、未弄脏，但仍没有命中服装条款。这是条件保留不等于检索成功的直接例子，后续应检查候选召回与重排阶段，而不只是加长提示词。

裁判也会犯错：首条案例的裁判声称包含“手机”的查询没有保留实物手机条件，这个理由值得质疑；已保留原始判断，未人为改分。因此条件保留率只能作为机器审计线索。

“未查询知识库”表示末轮没有发起新查询，不自动等同业务失败；多轮可能使用前轮证据，也可能需要澄清。“条件丢失”也不能单独等同回答错误，因为生成模型仍可看到用户原始消息。应同时检查工具查询、必要证据、最终回答三者。

本次没有改生产Agent的提示词、检索池大小、阈值或重排模型；新增的是诊断能力。评测工具与应用网页分开，网页交互没有变化。

## 接下来优先改什么

1. **条件更正时重新取证**：如过期问题变成跨店使用、无理由变成质量问题，应查新主题。不要所有多轮消息都强制重复检索。
2. **查看召回与重排中间结果**：针对手机、服装两例，判断是候选阶段没找到，还是重排排错；再决定改写补充或排序优化。
3. **政策说明与业务查询分开**：不需要订单号也能先说明适用规则；执行具体售后业务再要求订单信息。

这些是下一轮修复建议，本次没有执行，也没有用这30题调整生产参数。若后续修复，应另建未用于开发的测试对话确认泛化，不能只在本集追分。
