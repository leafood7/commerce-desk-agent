# 政策补证实验与语义修复

本批次先验证同源条款补全，再处理回答把“不承诺”写成“不会”、把条件规则改成唯一条件的问题。应用代码仅调整 `src/agents/answer_policy.py` 的共享回答约束，没有新增模型节点。简历未更新。

## 同源补证对照

固定代码、知识库、提示词和检索参数，对30道新增合成题（34轮）比较补证关闭／开启。26道单轮使用相同初始检索锚点；4段多轮各自运行 LangGraph，使用本地工具，并非 MCP 传输回归。

22道可回答单轮题中，原始标注下必要证据完整题数为18→22。复核发现第013题已有等价通用条款，按用户确认的等价证据口径应为 **19/22→22/22**；原始结果保留。单轮回答报告 tokens 为35,823→48,798，增加约36.2%。

不能将覆盖收益写成业务准确率提升。第015题两组都把非保证条款说得过强；第030题开启组出现唯一条件误写，但两组最后证据相同，不能直接归因于补证。第022题主要是解释完整性差异。题目为合成数据，出题者熟悉系统，结果不代表线上分布。

详见[消融报告](experiments/2026-10-25/context-ablation/同源补证消融实验报告-v1.md)及[用户确认复核](experiments/2026-10-25/context-ablation/关键案例复核结论-用户确认版.md)。一次连接失败的原始批次和显式续跑均保留；失败请求用量未知。

## 语义修复与验证

约束回答保留政策的确定程度、条件方向、适用范围与例外，避免将充分条件反推为必要条件；对于原文明示的禁止或强制要求仍直接应用。依据部分保留原条件连接词，以短引原文减少压缩改写造成的语义强化。

| 验证 | 结果及限制 |
| --- | --- |
| 首轮14题配对 | 13/14→13/14，已知015仍失败，保留失败后继续修订 |
| 第二轮8题配对 | 7/8→8/8，收益来自已知015；新增6题两组均通过 |
| 最终26道固定题与8轮对话 | AI辅助复核未发现目标类型的语义强化；不等于所有语义均正确 |
| 用户验收 | 对015、028、030关键片段确认；不是全量独立盲审 |
| 第二轮配对成本 | 8次调用/组，9,441→12,466 tokens，增加约32.0% |

两轮实验累计128次模型调用、接口报告247,574 tokens，无额外模型裁判调用。没有新增每轮调用，但更长提示词增加输入成本。仍有券面条件套用、无必要订单信息追问与来源标注不完整等问题；本轮未实现运行时引用校验。

详见[修复报告](experiments/2026-10-25/policy-semantics-fix/政策语义修复验证报告.md)及[用户验收](experiments/2026-10-25/policy-semantics-fix/用户验收确认.md)。既有107项离线测试已通过；本次另增加5项题集和配对执行器完整性测试；发布前复跑共112项相关离线测试全部通过（103项主回归＋9项知识库测试）。

## 可移植复现入口

`data/evaluation/policy_modality_cases.json` 汇总12道首轮定向题、6道第二轮定向题与2道已知失败题。它是已用于修订的回归集，不再作为未见测试集。默认只验证ID、政策原文和标注结构，不调用模型：

```powershell
.venv/Scripts/python.exe scripts/evaluate_policy_modality.py
$env:PYTHONPATH='src;tests;tests/agents'
.venv/Scripts/python.exe -m unittest test_policy_modality_evaluation -v
```

显式在线复现会将选定的合成问题及演示政策发送到本地配置的模型接口，产生费用；下面仅为命令示例。本次发布不再次执行在线评测：

```powershell
.venv/Scripts/python.exe scripts/evaluate_policy_modality.py --online --ids known-015,known-030 --output work/policy-modality-new-run.json
```

执行器固定证据和基础模板，仅替换修改前／当前回答约束，交替两组顺序，保存回答、接口用量、耗时及错误。评分仍需逐题核对，不以关键词自动判为正确。模型版本和SDK重试行为可能与历史批次不同，不保证复现相同措辞或成本。
