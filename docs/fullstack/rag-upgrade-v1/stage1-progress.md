# 阶段1进度：父子分块、原文阅读与显式范围

日期：2026-11-01。状态：第一批功能与边界验收完成；阶段1整体未收口。未部署到当前运行容器，未提交或推送。

## 已实现
- 新增parent_child入库策略，复用既有版本表的parse_metadata保存解析原文父章节和子块关系，不新增迁移。Markdown标题及纯文本法规条款可作为父章节边界。
- 检索可选parent_child上下文模式，返回原始子片段身份，不用父块合成文本冒充原有引用。去重、字符预算和20片段上限，遗漏显式记录；完整父块仍不等于政策证据充分。
- 管理员上传可标注商家、地区、渠道和商品范围，包含在配置去重哈希中；无标注的旧请求保留旧哈希。显式条件下，未知元数据不能证明适用。缺少标注政策所需维度时返回needs_scope。
- 工作台可填写已确认范围，更正时清空旧结果后重新检索，不继承未确认历史条件。当前仅支持显式字段，不声称自然语言自动识别或订单自动推断。
- 新增认证POST /api/v1/knowledge/read及MCP read_policy_source：读取当前有效版本的父章节，分页有next_offset、完整性标记、原文哈希和来源位置。校验组织、发布、有效期和当前提交的范围。API列表不返回整份父章节正文。
- 前端知识管理可选父子分块，政策检索可点击并继续阅读相关原文。当前由人点击；Agent自主阅读属于阶段3。
- 默认neighbors和规则模式不变；旧资料需新版本按父子策略入库，不能假装旧索引已有父子结构。
