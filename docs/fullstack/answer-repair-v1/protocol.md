# 最多一次回答修复：开发与验收协议

阶段3冻结候选和6家族新题结果原样保存。进入本阶段后该批题转为回归，不据此继续宣称独立提升。规则咨询与字段选择、跨章节缺口和业务审批边界保持。

新增reviewed_repair实验模式，默认仍原模式。初稿经程序及语义检查；可定位错误且现有证据无已知缺口时最多修复一次，再经完整程序与语义检查。无效引用、工具字段越界、非JSON结构、未读条款或无法解析的引用、权限/取消、未知调用结果不自动修复。修复不调用业务工具或追加检索。所有阶段共享累计调用、token与取消语义，修复尝试先持久占用，不因恢复重置。

至少覆盖：原稿直接通过、语义错误修复通过、明确程序任务约束错误修复通过、伪造引用不修复、修复新增错误、二次检查失败、超时、无证据、缺口、预算耗尽、取消、重复执行不再调用、草稿对公开结果/SSE/历史隔离。无后审(contract)、单次后审(reviewed)、一次修复(reviewed_repair)分开记录。注入模型测试只证明机制，不写成自然模型准确率。真实模型仅在原剩余授权内用新编隔离数据，达128次或1元即停止。

阶段3基线启动和订单大小写夹具错误单列；付费规则回答与候选回答均未重放。新题中两项人工复核仍按真实用户回复或pending记录，不由模型批准替代人工结论。
