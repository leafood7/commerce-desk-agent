# 长上下文管理协议 v1（开发前冻结）

范围：新工作台两类模型入口（intent_router与return_decisions）、售后会话/恢复、公开上下文说明；旧Streamlit/通用toolkit模型入口另列兼容范围，不声称本轮改造。默认不调用额外摘要模型。历史原文继续存MySQL，使用带消息ID的确定性有界提取摘要，不把旧助手内容/旧工具结果提升为事实。模型本来不读取全历史，不以虚构旧版超限作性能提升基线。

采用三种离线对照：不带历史的现有输入、预算组装、预算组装＋历史提取摘要。固定当前任务/结构化条件/实际观察/必要政策原文；不得静默截断任务、原因、必需证据。UTF8序列化字节＋消息框架预留作为保守token上界，非DeepSeek精确tokenizer；输出和工具空间预留，不能伪称实际token节省。

历史只在同组织/用户/会话/当前明确订单范围读取，当前无订单时不继承其他订单事实。仅取创建时间不晚于当前run的历史，限定SQL窗口80消息（加1检测截断），近期完整对话单元优先；较早用户原话可生成有来源的摘要条目，明确截取与覆盖范围。摘要不承诺覆盖所有旧消息，窗口外历史标为省略；关键条件来自当前图状态和用户结构化输入。工具调用/结果若有则以整个对话单元保留或移除，不拆配对。

快照版本存现有私有FlowAction空间，含算法版本、当前条件来源、源消息ID、预算与省略指标、输入指纹。对外只发布当前run的条件与省略/预算说明，不公开旧摘要正文、checkpoint、其他订单或内部模型草稿。旧快照损坏不作为事实使用。关键输入超限则不发模型请求，退回现有确定性合法动作；不能利用摘要执行审批或写入。业务执行仍按实时工具和预览hash重验。

验收先冻结24场景，覆盖100+历史消息、最新更正、切单、未知、假退款历史、旧政策、预算边界、工具配对、损坏快照、隔离、恢复与公开输出。离线对照分别报告关键字段/证据保真、原文/上界长度、省略与降级，不将更短称作更正确。替身验证真实API/图/持久状态，新增真实模型请求0；已有48次授权耗尽。

完成标准：两模型入口统一预算预检；同会话长历史可有界组装且有来源；关键字段不被历史覆盖；超限无模型HTTP；API/SSE/历史不泄露私有摘要；前端显示当前关联与待核实条件；专项离线与业务回归通过。MySQL与本地容器按可用环境验收，所有临时目录设D盘。仅较大跨越完成后新增总结16；不自动commit/push。
