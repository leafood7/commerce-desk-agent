100篇确定性合成Markdown，每篇100个结构片段，共10000片段；50/100篇分档。与真实政策语义集合独立，不把合成重复算语义多样性。使用新建隔离MySQL数据库、独立文件目录、按新组织ID隔离真实Chroma集合。通过真实应用上传路由(TestClient)、持久入库worker、发布及生产KnowledgeRetriever；不直接插入已处理片段。TestClient不等同浏览器或跨进程HTTP全链路。
记录上传/解析/向量/发布耗时、增量数量、SQL与Chroma数量、缓存构建次数、冷暖查询P50/P95、进程RSS、磁盘、实际模型版本和文件哈希。50篇后新增50篇，验证未重复生成旧版本；撤回目标文档后不得返回旧证据；其他组织与未发布、过期版本不得返回。
验收：100文档ready且发布、SQL/向量各10000、源文件哈希一致、重复上传不增加版本、增量数量符合预期、撤回/组织隔离通过；固定探针必要片段全部命中；容量暖查询P95目标5000ms，超出如实记录未达标。索引时限3600秒；失败保留完整轨迹与中间状态，不删现有业务库或卷。
