# 长文档及规模RAG验证：实现前标准 v1

本轮聚焦原路线第3项，不新增售后业务、不调用付费模型、不读取封存最终题。全部为作者合成开发资料，不能称为独立盲审、企业级规模或线上准确率验证。

冻结32条开发问题，覆盖范围、期限、使用例外、缺陷条件、排除条件、最新更正、事实缺失及无关问题。正例要求跨章节必要原文；负例记录政策召回但不算事实可答。题与评分原文仅用于运行结束评分，召回仅用问题和明确的商家／当前政策绑定。

语料为12、60、180份嵌套集合；含6份8千至1.5万字符长文档、相似商品和期限干扰、同文档另一分支，以及其他商家、撤回和过期资料。必须报告实际字数、chunk数量、索引时间、磁盘占用、语料模板性及范围过滤代价。

比较8种预先指定配置：全商家有效资料的结构切块600基线；同参数固定切块600；结构切块300；候选池12→24；top3→5；关闭重排；按用户明确政策版本限定；版本限定＋显式跨条款引用扩展。除被比较因素外参数一致，记录混杂因素。上下文预算2400字符、距离阈值0.65、重排阈值-2；使用固定本地BGE向量和重排修订、BM25与RRF。无生成模型。

引用扩展仅从实际已召回的锚点解析“参见／另见／详见第N条”，在当前权限检查后的同组织同版本片段内查找。最多2跳、8个片段，总长不超预算；循环、缺失、超限需有记录。不得读取评分原文、跨商家补内容或把扩展后有片段称为结论正确。生产默认保持原模式，实验模式须明确启用。

测量初始召回、选定证据的必要原文覆盖／完整覆盖、其他分支预标注原文出现、跨商家及失效来源泄露、空检索、负例检索、上下文长度、候选数量及p50/p95耗时。配置顺序按题轮换，首轮预热与索引构建单独记，仍说明本机缓存及并行工作影响。原始轨迹保留，输出拒绝覆盖、题号与配置无效时先拒绝。

先完成小批次成本与耗时探测；本地无付费调用，若规模运行过慢允许保留已完成档并将未完成档标为未验证，不降低阈值或删难例制造改善。不得根据同开发集结果声称候选默认启用；关键与争议案例需作者参与复核，未完成复核不能编造人工结论。

验收包括冻结哈希、解析／引用边界单测、真实本地召回与重排、MCP权限／撤回再校验、适当业务回归、实验报告和编号总结。无需为本轮重复扩建Docker、Redis或新调度框架。
