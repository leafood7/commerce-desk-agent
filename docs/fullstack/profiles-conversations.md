# 会话与受控配置版本：本地使用说明

日期：2026-10-29。项目D:\VScodeProgects\commerce-desk-agent。工作台 http://127.0.0.1:15173 ，API http://127.0.0.1:18082 。

## 配置版本

管理员进入“配置版本”，创建草稿，再选择版本发布。客服可查看当前发布配置，不能创建/发布。草稿不会自动生效，已保存版本正文不提供修改接口；变更创建新版本。发布带expected_revision，其他管理员先发布后，过期请求返回409，刷新核对后才可再次发布。

当前白名单：rules；只有服务端已经明确启用模型时才提供server_default。页面不能设置地址、密钥、权限、审批、配额或任意模型名称，不能把服务器规则模式改成模型模式。模型输出选项128/256且不超过服务端上限；温度固定0。模板仅intent_v1，正文由代码维护，没有开放自由提示词正文编辑。

检索候选数1—3和标准/友好用语可版本化。候选数会实际传给知识工具，友好用语仅增加问候，不修改订单/审批事实。默认仍3、标准用语、规则模式；配置能力不代表更少候选的检索质量更好。

创建运行时，与Run、用量及入队同事务保存RunProfile快照，包含版本ID、配置指纹、模板指纹和安全参数。worker消费及人工恢复均读取该快照，不使用后来发布的新版本替换旧运行。服务端模型被关闭、模型绑定或模板变化、输出上限收紧时，旧运行不能借快照绕过新的限制；禁用新模型调用并记录profile_guard，原快照保留。

旧运行没有快照时返回legacy_unrecorded，不补造历史版本；执行保持规则模式。模型绑定用私有指纹校验，不公开地址/密钥；没有承诺记录供应商不可控的底层模型修订。人工取消等控制提示仍使用服务端固定文案。

API：
- GET /api/v1/runtime/config：本商家当前配置及可用白名单。
- GET/POST /api/v1/runtime/config/versions：管理员查看/创建版本。
- POST /api/v1/runtime/config/versions/{id}/publish：管理员发布，需expected_revision。
- GET /api/v1/runs/{id}/configuration：仅运行本人查看快照。

## 会话记录与恢复

“会话记录”只展示当前账号已公开的human/assistant消息，按商家与所有者隔离；私有图状态、工具凭证与草稿不参与查询。进入会话可加载更早消息、查看近期流程，在同会话开始新任务，或打开已有售后流程。

恢复只读取原运行并按需续订进度，不创建新的任务或自动提交。新任务不自动沿用旧订单和条件；明确准备新任务时清空输入。后续问题会使用相同conversation_id归组，但不会把历史助手回答作为政策证据，也没有新增语义长期记忆或历史压缩。

消息默认返回最近100条，按时间及ID顺序展示；before游标加载更早页。游标必须属于同一会话，非法/跨会话游标422。相同时间戳用ID打破并列。新问题保存全文（上限1200），旧记录已经截断的内容不凭空补造。会话列表仍是原偏移分页；活跃更新可能使列表排序变化，不保证跨页全局快照。

API：
- GET /api/v1/conversations：本人会话列表。
- GET /api/v1/conversations/{id}/messages?limit=50&before={message_id}：公开消息及next_before。
- GET /api/v1/conversations/{id}/runs：本人会话近期运行。
- POST /api/v1/runs：可携带本人conversation_id，不接受客户端覆盖配置、权限或配额。

## 运行和验证

迁移0006_profile_versions只新增三张表。Docker按已有run-container-acceptance.ps1运行Config/Build/Start/Test；主机兼容模式先执行workbench.cli migrate。镜像、缓存和数据继续在D盘，不购买服务器。

测试会在演示商家验证发布，并恢复原有效设置；原来没有发布版时可能创建等价默认版用于恢复。不可变版本及审计历史保留，不删除记录。复验时不要把这些元数据变化误认为业务办理或模型调用。

真实模型默认未启用。本轮只用替身验证模型参数与保护机制；真实MCP、SQL业务、RAG上传和浏览器链路另行实测。下一步是隔离备份下的向量重建及应用恢复，不将当前版本称作生产多副本或完整灾难恢复。
