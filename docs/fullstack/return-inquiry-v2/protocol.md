基线为当前main；8项开发契约与6个未用于开发的新问题家族分开保存。留出题由作者预编，不声称外部独立盲审；候选冻结后才运行留出，之后修改则整批转回归。旧封存answer_trust题不读取。

任务层：不明目的先澄清；规则/字段无需整套办理材料；资格核对不创建申请；明确申请仍须预览确认和独立审批。旧保存配置默认不新增澄清，新增开关通过配置版本固定。

证据层：主条款与明确跨条引用双向关联；读取限定当前组织、有效版本、服务端位置，不把关联自动判定为例外。引用未解析、窗口未覆盖或预算不足须呈现缺口；不因主条款已命中视为整题完整。最多2读4000字符、1补检，额度不随更正重置。

记录目标状态、必要条款、未读关联、无必要阅读、重复窗口、额外补问、原始回答、审查结果、用量/费用/耗时。旧题回归、新家族、模型替身与真实模型分别报告。开发前不预设提升百分比。留出测试不参与开发调优，人工关键复核称作者参与复核。
