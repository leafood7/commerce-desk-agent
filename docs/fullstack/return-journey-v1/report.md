# 新退货问题整链路诊断：先冻结题，再看结果

日期：2026-11-01。本轮完成验证与诊断，没有修复或调参生产系统；没有将发现问题后的重跑称为独立提升。源码走读仍暂停，没有commit或push。

## 结论

确实存在多余补问、无必要阅读、可避免重读，以及必要证据未进入回答集合的问题。当前没有证据支持扩大默认启用阅读模式。

首批16条预冻结新题、8个家族，分别跑关闭/开启阅读，共32次真实流程。按当前轮证据和预定程序目标，两条路径均10/16达成，必要句覆盖均14/16，多余补问或要求补齐办理条件均3/16。开启侧在范围题找回依据，却在数量更正题退化；不能只看总数，也不能把找回依据归功于阅读工具：该改善实际来自补检。

主集没有触发原文阅读，所以不能从“0次无效阅读”推断阅读策略没有问题。随后另行冻结4条探索题，真实跑8次流程；该批是看到主集结果后编制，不并入16题、不称独立测试。

探索批实际触发5次模型阅读决策和5次原文阅读：其中1次在当前问题必要句已齐时仍读整章；另1次是数量更正后重读相同版本、相同窗口。后者属于可通过安全证据复用减少的重读，不直接判为语义错误。程序原始计分将两者合成2次可避免读取；本报告将它们分开。两条探索路径均3/4达到程序目标，不能由4题推断整体净收益。

## 实际发现与证据

### 1. 纯规则问题仍被当成办理

journey-001只问“办法管哪些货，暂时别提交工单”，却被要求核实商品是否使用。journey-003只问最晚时点，也被问使用状态。journey-005只问照片能否证明缺陷，却被转入等待实际质检。两边都出现，说明阅读开关不能解决前面的任务目的识别。001已由用户确认，003/005为作者依据冻结任务标签的初审。

journey-006主结论正确，但开启侧附带27天期限、商品范围、订单号、物流状态和签收时间；用户确认应记录非所问信息。语义检查批准不等于回答足够聚焦。

### 2. 有“漏取必要证据”，不能一律归为模型漏读

journey-014必要条件位于章节字符4653处，当前合法原文窗口从0开始，两次各2000字符仍到不了。实际检索偏向背景段落，程序的问题级需求又没有把“末尾限制”正确转成所需条件。

后验诊断中，人工直接提供准确条款原句，真实检索可以找到它。这只证明原句已在索引中，不能证明自动Query改写有效，也不算原题得分改善。

因此本轮未证明存在“模型明知条款在合法可达窗口内却故意不读”的错误；已经证明的是检索定位、问题级证据需求和默认阅读起点的组合缺口。按原窗口预算不应硬读到无限长，也不应假装条款齐全。

### 3. 更正时丢掉仍有效的政策

journey-011只把数量改为2，同一政策版本没有变化。开启侧清空上一轮取证，又已用掉一次补检额度，第二轮无检索命中、无可读目标，停在保守提示；关闭侧仍达到预览。

后验校验表明，上一轮真实搜索得到的5个来源现在仍能通过有效性检查。这个结果支持研究“重新验证并复用政策证据”，不支持重置累计预算，更不能复用旧订单或旧数量的质检事实。

### 4. 读到了，不等于能放进回答

journey-013必要条款已取得，但生成输入的保守上界6942，超过6000，发出模型请求前即停止。journey-014上界6764，也被阻断。

explore-read-003只问办理天数，窗口句已取得，却又读了1834字符整章；随后输入上界达到13065，无法生成回答。关闭侧也因过宽上下文未完成。这不是供应商超时，是当前证据组装和输入预算的衔接问题。

先减少同一来源窗口与子块的重复、只保留当前问题必要条款及明确例外，再研究预算是否合理；不能靠临时增大预算掩盖问题。

### 5. 真实字段问题仍调用不必要的回答链

journey-015只查缺失签收字段，最终确定性文字能准确说明未知，但仍进入模型生成/检查：一侧草稿未通过程序契约，另一侧被语义检查拦截。journey-016的到账工具能力说明正确，却有额外不确定提示和重复说明。适合直接展示实际字段或工具能力边界的任务，应单独评估无需模型的路径。

## 怎样做的

- 新建隔离MySQL库和新订单；评测业务事实只来自新库，日常库仅只读核对申请总数，未取客户/订单正文，未外发现有业务库或历史会话。所有政策为本轮人工演示条款，9天/27天只是演示规则，不代表真实平台或法律期限。
- 实际运行API→持久LangGraph→HTTP MCP→BGE/Chroma/重排→业务检查/原文阅读→回答契约与单次语义检查→API结果及SSE事件。客户端是TestClient，不是浏览器，也没有在线用户或线上流量。
- 关闭/开启阅读使用同一冻结62模块代码，均允许现有受限模型决策与核验后回答；top_k=2、父子检索上下文900字符、分块240/重叠20、输入预算6000、输出256/1024、温度0、思考关闭、历史关闭。生成/检查超时上限30秒，现有决策适配器保留10秒硬上限；两边相同。
- 交替运行版本，各题各路径一次；更正题保留前序。未对失败模型调用重试。首两题费用线性预估约0.047元，未据此修改参数。
- 证据覆盖只统计实际搜索/阅读，不把evaluate_return自带的完整映射当成RAG召回成功。这个口径用于评价RAG，不能理解为其他业务工具从未返回过相关原文。
- 主集仍由同一实现者编写，只是未用于前期实现、预先冻结的新题，不是第三方盲测。每家族两题相关，不计算显著性，不外推客服准确率。
- 本轮只核对到说明、预览或等待事实；没有确认申请、批准退货或执行模拟受理。写工具有评测阻断替身，隔离库退货申请数量为0。
