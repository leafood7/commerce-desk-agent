# 阶段3冻结协议：退货Agent按需阅读

冻结日期：2026-11-01；开发验证，不读取封存最终题，不发真实付费模型请求。

目标：在现有guided_v3退货LangGraph上补充基于实际观察的原文阅读选择。保留原有规则与模型决策对照，新增功能默认关闭，管理员只在服务端允许时开启。

每次运行（包括补充、更正和恢复）最多一次补检、两次原文阅读；单次最多2000字符，累计4000字符，共享现有工具、时间、模型次数与上下文预算。初次检索不算补检。更正使证据与阅读目标失效，但不恢复运行级预算。模型只能选择当前允许动作和服务器列出的目标，不能指定文件路径、版本、偏移或审批写入。

可读目标仅来自真实检索命中章节、检索或阅读工具返回的同版本明确关联章节，或同章下一页。完整父章节已经取得时不重复读。补读失败/撤回/预算耗尽明确记录缺口，不自动重试或声称已读全。独立业务事实转查单、质检或补问；不把缺整套办理材料等同当前规则问题不可回答。

验收：补读找回遗漏条件；跨章明确例外；充分证据零阅读；非法目标拒绝；来源撤回/跨组织/篡改阅读片段拒绝；长章分页与两次上限；失败降级；更正清证据不重置预算；未知状态仍补问，质检不能靠用户声称补齐；真实MCP与持久化图回归；公开输出无模型自由文字。记录工具次数、阅读字符、停止原因和任务状态。模型替身结果只证明工程约束，不能证明真实模型净改善。
