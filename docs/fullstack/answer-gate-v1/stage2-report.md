# 阶段2：回答核验后发布（2026-11-01）

## 完成了什么

上一阶段让系统能找到片段并阅读原文。本阶段补上“找到依据之后，回答是否越界”的控制链路：生成结构化草稿 → 程序校验引用和工具字段 → 单次语义检查 → 发布可读回答。检查失败、超时、格式错误或证据失效时显示明确提示，不自动修复、不追加检索。

政策结论只能引用本轮允许使用的证据；订单事实由实际字段生成展示文字。用户最新条件和证据缺项随请求传入，历史助手回答不当作依据。缺少整个流程所需条款，不自动等于无法回答当前一个问题。

草稿与公开结果分开保存。工具进度即时展示，草稿不写入公开消息、普通结果、SSE事件、会话历史或LangGraph检查点。发布前重新核对权限、取消状态、配置和证据有效性。纯订单查询保持字段展示，审批和业务写入仍由原规则控制。旧AG-UI入口不属于本次新工作台验收范围。

后台提供原文展示、仅程序校验、程序加语义检查三种配置；默认仍为原文展示。配置受服务端开关、模型别名、提示模板和输出预算约束。直接政策问答最多生成及检查两次模型调用；混合流程还需计入已有路由调用。调用前预留额度，未知用量不归零；失败或未完成的私有调用不自动重放。
