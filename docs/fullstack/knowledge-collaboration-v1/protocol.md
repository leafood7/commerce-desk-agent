# 受限检索、回答与核验角色协作实验

保留single默认流程，collaborative显式实验开关。只用于规则问答和退货流程中的只读政策问答，不改变订单行资格、审批、写入或退款。检索角色只可搜索和阅读当前用户有权的有效来源；回答角色只生成结构化草稿；核验角色只判断支持关系。由LangGraph调度，修复最多一次且仍受原模式约束。

初始检索仍为两模式共用基线；协作检索角色可以在原2读4000字符/1补检及全局调用/token额度内选择补读/停止，不能调用业务工具。结构交接经过当前来源重新校验；检查点、原稿、修复稿私有，公开仅角色进度与经过核验的输出。恢复不重置预算、不重发不明结果。

对照需要包括正常、跨章节、空检索、范围不明、权限/来源变化、非法模型动作、某角色失败、取消、预算耗尽、恢复隔离及原/修复稿不泄露。真实模型测试仅用原授权剩余44请求/0.764206元以内的新编演示资料；不靠增加角色数量声称质量提升。若收益不明保留实验默认关闭。
