# 取证、回答与复核协作：阶段实验报告

这次将政策问答分为取证、回答、复核三个职责，由LangGraph调度；复核未通过时只在开启有限修复的情况下进入一次修订。单流程仍保留为默认。这里只读咨询和办理中的政策解释采用协作，不改变订单资格、金额、确认、独立审批与业务写入。

取证职责有真实搜索/原文阅读工具白名单，受同一流程2次阅读、4000字符和1次补检限制；所有角色共享调用与token额度。交接包括有效来源、版本与内容校验，不能把上一角色的自然语言结论当证据。独立SQL检查点保存进度，恢复会再次核对当前发布状态。完成的补检/原文读取可以复用，结果不明的不重发；已撤回来源不得继续交接。原稿、修订稿和内部上下文不会放进公开Run、历史或SSE。
